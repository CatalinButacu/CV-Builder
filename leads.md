# Job Leads

Filled daily at 08:00 Bucharest by a Claude routine. Newest day first. Fit is scored 1-5 against resume.tex. Edit the Search criteria table on GitHub to change what the routine looks for; type in the Status column to track a lead.

## Search criteria

| Setting | Value |
| --- | --- |
| Roles | Machine Learning Engineer; AI / LLM Engineer (RAG, agents, GenAI); C++ Engineer |
| Location | Iasi (on-site or hybrid), or remote open to people based in Romania |
| Seniority | Any; show it, and let the fit score account for it |
| Freshness | Posted in the last 14 days, or no date shown but the posting is still open |
| Sources | LinkedIn, eJobs.ro, BestJobs, Hipo.ro, and company career pages |
| Already applied | CGM, ESET, Itility, Levi9, think-cell (list them, but mark them) |
| Minimum fit | 3 |
